# Design Foundation

The Design Foundation defines the visual language of FinTrack.

These documents establish reusable design tokens and principles that every component must follow.

Components should **consume** these rules rather than redefining them.

# Purpose

The Design Foundation provides consistency across the entire application.

It defines:

* Color system
* Typography
* Spacing scale
* Layout grid
* Border and radius tokens
* Elevation system
* Motion language
* Iconography

These are shared across every component and every screen.

---

# Design Tokens

Wherever possible, components should reference design tokens instead of defining values directly.

Examples include:

* Colors
* Font sizes
* Spacing
* Border radius
* Shadows
* Motion durations

---

# Relationship to Components

The Design Foundation answers:

> **How should the interface look and feel?**

Component specifications answer:

> **How should individual UI elements behave?**

Together they form the complete design system.

---

# Principles

* Define once.
* Reuse everywhere.
* Never duplicate design decisions.
* Keep visual language consistent across the product.

The Design Foundation is the visual source of truth for FinTrack.
