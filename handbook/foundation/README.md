# Foundation

The Foundation documents define **why FinTrack exists**.

Everything else in the handbook builds upon these documents.

No implementation details should appear here.

---

# Reading Order

1. Manifesto
2. Vision
3. Product Blueprint

# Documents

## Manifesto

Defines the beliefs and philosophy behind FinTrack.

Read this first.

## Vision

## Product Blueprint

Defines the overall product structure.

Explains:

* Product scope

# Responsibilities

The Foundation section answers questions such as:

* Why are we building this?
* Who is it for?
* What problems are we solving?
* What principles guide product decisions?

---

# What Does Not Belong Here

Do not include:

* UI specifications
* Component documentation
* Technical architecture
* Database design
* API contracts
* Implementation details

Those belong elsewhere in the handbook.

---

# Dependency

Every document in the handbook assumes that the Foundation documents have been read first.
